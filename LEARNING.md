# Continuous Learning Contract

Agents continuously improve through externalized memory and skills.

Loop:
OBSERVE -> VERIFY -> EXTRACT -> STORE -> RETRIEVE -> APPLY -> MEASURE -> CONSOLIDATE

Memory is persistent state, not an infinite prompt. Retrieval is scoped and current. Stale or contradictory knowledge is downgraded or invalidated. Secrets and credentials never enter memory.

The system can continuously improve its procedures and external knowledge without claiming that model weights themselves are retrained.
