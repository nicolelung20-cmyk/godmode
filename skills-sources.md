# Upstream skill sources

Curated sources used by the Elevat agent skill layer:

- https://github.com/obra/superpowers — disciplined engineering workflows and agent bootstrap patterns.
- https://github.com/anthropics/skills — official Anthropic skill examples and skill-authoring tooling.
- https://github.com/addyosmani/agent-skills — spec-driven development, context engineering, testing, security, review, and agent personas.
- https://github.com/vercel-labs/skills — portable skill discovery/installation tooling.

These repositories are treated as reference sources, not blindly trusted executable payloads. Review third-party skills before installation. GitHub explicitly warns that skills may contain prompt injections or malicious scripts.
