# Using Superpowers

1. Define the outcome and acceptance criteria before editing.
2. Search the repository and upstream references for existing solutions.
3. Break work into atomic, independently verifiable tasks.
4. Implement incrementally; keep changes reversible.
5. Run the narrowest useful tests after each meaningful change.
6. Perform a fresh-context review for security, correctness, regressions, and missing requirements.
7. Report evidence, not confidence.
8. Do not broaden scope merely because additional work is possible.
