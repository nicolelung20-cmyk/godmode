# Security Hardening

- Search for exposed secrets and unsafe credential handling.
- Review authentication, authorization, input validation, SSRF/injection surfaces, dependencies, headers, logging, and rate limits.
- Prefer server-only secrets and least privilege.
- Fix verified vulnerabilities with the smallest safe change.
- Never weaken a security control merely to make deployment pass.
- Re-test after every security fix.
