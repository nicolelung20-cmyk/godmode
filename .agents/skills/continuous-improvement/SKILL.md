# Continuous Improvement

After every non-trivial task:
- Capture what worked and why.
- Capture what failed and the evidence.
- Convert repeatable lessons into a skill, test, checklist, or automation when justified.
- Add regression coverage for repaired failures.
- Prefer measurable improvement over subjective confidence.
- Periodically consolidate overlapping skills and retire stale guidance.
- Never self-modify production behavior solely from an unverified lesson.
