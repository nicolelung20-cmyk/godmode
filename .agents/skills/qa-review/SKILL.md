# QA Review

- Review the original requirement and acceptance criteria.
- Test the critical path and likely failure modes.
- Check edge cases, error handling, accessibility where UI is involved, and observable runtime errors.
- Separate confirmed defects from hypotheses.
- A release is ready only when required checks and smoke tests pass.
