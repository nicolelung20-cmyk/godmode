# Web Performance

- Establish a baseline before changing performance-sensitive code.
- Inspect bundle size, network waterfalls, server latency, caching, rendering, images, fonts, and database/API latency.
- Optimize the largest verified bottleneck first.
- Re-measure after each meaningful optimization.
- Preserve correctness and accessibility.
